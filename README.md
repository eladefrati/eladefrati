### Mac apps

- [Tattle](https://github.com/eladefrati/tattle): a menu bar app that shows what your Mac is doing and explains it in plain language.
- [LimitGauge](https://github.com/eladefrati/limitgauge): your Claude usage limits in the menu bar, with a warning before you hit one.
- [OnTop](https://github.com/eladefrati/ontop): pin any window above all others.

### Ableton Live

- [Ableton Live Test Harness](https://github.com/eladefrati/ableton-live-test-harness): lets coding agents test their own work inside Live. Built on AbletonOSC.
